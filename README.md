# Azotus public campaign totals

Only public GoFundMe totals are stored here: amount raised, goal, donation count, currency, source URL, and last check time. No donor or payment information is collected.

The workflow checks GoFundMe about every five minutes using free standard GitHub Actions runners for this public repository. Jobs may be delayed. Failed checks keep the last verified figures.
